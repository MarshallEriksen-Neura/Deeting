## 安装方法

### 方法 1：右键打开（推荐）

1. 下载 `.dmg` 或 `.app.tar.gz` 文件
2. **右键点击**文件 → 选择"打开"
3. 点击"打开"确认

### 方法 2：系统设置允许

1. 下载并打开应用
2. 如果出现"无法验证开发者"提示：
   - 打开"系统设置" → "隐私与安全性"
   - 找到被阻止的应用，点击"仍要打开"
   - 点击"打开"确认

### 方法 3：终端运行（高级用户）

```bash
# 移除隔离属性
xattr -cr /Applications/Deeting.app

# 或者直接运行
/Applications/Deeting.app/Contents/MacOS/deeting
```
