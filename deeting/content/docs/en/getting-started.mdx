## What is Deeting

Deeting is an intelligent context and memory hub.

It is not meant to be just another chat box. The product is designed to keep conversation, memory, knowledge, tools, and runtime capabilities connected so users can work across longer tasks without constantly rebuilding context.

If you are new to Deeting, the simplest mental model is:

- it is a place to talk, execute, and coordinate tasks
- it can connect models, tools, plugins, and MCP capabilities
- it focuses on context continuity instead of one-off answers
- it offers both a web experience and a more local-runtime-oriented desktop app

## Who should read this

This page is useful if you are:

- a new user trying to understand where to begin
- a power user evaluating the desktop app
- a developer planning to integrate external capabilities
- a contributor trying to understand the product at a high level

## Suggested first-run path

1. Sign in
2. Start with chat
3. Explore assistants and available capabilities
4. Try the desktop app if you want deeper local integration
5. Continue into integration or developer docs only when you need them

## Areas you will use most often

- `Chat` for conversation and task execution
- `Assistants` for task-focused workflows
- `Docs` for public product and developer guidance
- `Dashboard` for settings, logs, knowledge, plugins, and other panels

## Three things worth understanding early

1. Web and desktop are related, but not identical
2. Visible configuration does not always mean the runtime path is ready
3. Public docs, developer docs, and experimental notes serve different purposes
