title: 桌面端技能存储路径

---

## 概览

桌面端（Tauri）在启动时会扫描多个目录来注册本地技能：**官方技能**、**Deeting 受管用户技能**，以及 **共享代理技能目录**。

扫描逻辑由 `resolve_local_skill_scan_targets()` 统一管理，返回扫描目标后逐目录遍历、解析 `deeting.json`，并写入本地 SQLite。

## 官方技能（Official Skills）

官方技能随应用一起打包分发，用户不可修改。

| 环境 | 路径 |
|------|------|
| 开发模式 | `packages/official-skills/` |
| 生产打包 | `{resource_dir}/official-skills/` |

- 打包配置：`tauri.conf.json` 中 `"packages/official-skills/": "official-skills/"`
- 数据库标记：`system_plugin`
- 当前包含：`memory`、`crawler`、`ingestor`、`expert_network`、`monitor`、`provider_registry`、`skill_manager`、`weather-plugin`

## Deeting 受管用户技能（Managed User Skills）

用户技能存放在 Tauri 的 `app_data_dir` 下的 `skills/` 子目录。

应用标识：`com.deeting.app`

| 操作系统 | 路径 |
|----------|------|
| macOS | `~/Library/Application Support/com.deeting.app/skills/` |
| Windows | `C:\Users\{user}\AppData\Roaming\com.deeting.app\skills\` |
| Linux | `~/.local/share/com.deeting.app/skills/` |

- 数据库标记：`user_skill`
- 目录不存在时会自动创建
- 用户可通过 `install_skill_from_repo` 从 Git 仓库安装技能到此目录
- 卸载时只允许删除此目录下的内容（安全校验）

## 共享代理技能目录（Shared Agent Skills）

桌面端还会扫描用户主目录下的共享代理技能目录，用来直接接入 `npx skills add` / OpenClaw 生态安装出来的技能。

| 操作系统 | 路径 |
|----------|------|
| macOS | `~/.agents/skills/` |
| Windows | `C:\Users\{user}\.agents\skills\` |
| Linux | `~/.agents/skills/` |

- 这些技能会被当作本地用户技能注册和调用，但目录本身不由 Deeting 管理
- Deeting 不会把 skill 再复制到 `app_data_dir/skills/`
- 卸载这类技能需要回到外部生态自己移除，例如 `npx skills remove ...`

## 技能运行时（Runtime）

已安装技能的依赖环境存放在用户技能同级的 `.runtime` 隐藏目录下：

```
{app_data_dir}/skills/.runtime/{normalized_skill_id}/
```

| 运行时 | 包管理器 | 依赖标识文件 |
|--------|---------|-------------|
| Python | uv | `requirements.txt` |
| Node | npm | `package.json` |

运行时状态：`needs_install` → `installing` → `ready` / `install_failed` / `needs_reinstall`

## 目录结构总览

```
~/Library/Application Support/com.deeting.app/   (macOS 示例)
└── skills/
    ├── my-custom-skill/                  # 用户技能
    │   ├── deeting.json                  # 技能清单
    │   ├── main.py                       # 入口文件
    │   ├── requirements.txt              # Python 依赖
    │   └── llm-tool.yaml                 # 工具声明
    └── .runtime/                         # 运行时目录
        └── my-custom-skill/
            └── .venv/                    # Python 虚拟环境

{resource_dir}/                           (应用打包资源)
└── official-skills/
    ├── memory/
    │   ├── deeting.json
    │   └── main.py
    ├── crawler/
    ├── skill_manager/
    └── ...
```

## 扫描与注册流程

```
App 启动
  └─ register_local_skills()
       └─ resolve_local_skill_scan_targets()
            ├─ official-skills 目录 → system_plugin
            ├─ user skills 目录   → user_skill
            └─ ~/.agents/skills → user_skill
       └─ 遍历每个子目录
            ├─ 读取 deeting.json
            ├─ upsert_local_skill_install → 写入 SQLite
            ├─ collect_local_skill_tool_bindings → 注册工具
            └─ index_local_skill_bundle_asset → 向量索引
```
