## 功能概述

桌面端对象存储（Desktop Object Storage）用于解决以下场景的文件存储需求：

- **聊天附件上传**：图片、文件等聊天附件的持久化存储
- **视频输入处理**：Spec Agent 视频生成场景中的图片、音频、视频输入
- **大文件支持**：突破浏览器 base64 存储限制，支持更大文件上传
- **本地知识库**：知识文件的外部存储备份

数据流向：前端 → Rust 后端生成预签名 URL → 前端直传 OSS → 返回访问链接

## 支持的存储提供商

| 提供商 | 特点 | 适用场景 |
|--------|------|----------|
| **Cloudflare R2** | S3 兼容、无出口流量费、全球 CDN | 海外用户、流量较大的场景 |
| **阿里云 OSS** | 国内访问快、生态完善 | 国内用户、已有阿里云基础设施 |

## 配置步骤

### 1. 进入设置页面

打开桌面端应用，点击左下角头像 → **设置** → **存储设置**

### 2. 启用对象存储

开启「启用对象存储」开关，选择提供商类型。

### 3. 填写配置信息

#### Cloudflare R2 配置

| 字段 | 说明 | 获取位置 |
|------|------|----------|
| **Bucket** | R2 存储桶名称 | R2 控制台 → 存储桶列表 |
| **Region** | 区域代码 | 固定填 `auto` |
| **Endpoint** | S3 API 端点 | R2 控制台 → 存储桶 → S3 API 端点 |
| **Public Base URL** | 公开访问域名 | 存储桶 → 公开访问 → 自定义域名或默认域名 |
| **Access Key ID** | 访问密钥 ID | R2 令牌 → 创建 API 令牌 |
| **Secret Access Key** | 访问密钥密文 | 创建令牌时显示，仅可见一次 |
| **Path Style** | 路径样式访问 | 通常关闭（使用虚拟主机样式） |

#### 阿里云 OSS 配置

| 字段 | 说明 | 获取位置 |
|------|------|----------|
| **Bucket** | OSS 存储桶名称 | OSS 控制台 → Bucket 列表 |
| **Region** | 地域节点 | Bucket 概览 → 地域，如 `cn-hangzhou` |
| **Endpoint** | 访问域名 | Bucket 概览 → 外网访问 Endpoint |
| **Public Base URL** | 自定义 CDN 域名 | 可选，如不填使用默认域名 |
| **Access Key ID** | AccessKey ID | RAM 控制台 → 用户 → 创建 AccessKey |
| **Secret Access Key** | AccessKey Secret | 创建时显示，仅可见一次 |
| **Path Style** | 路径样式访问 | 通常开启（使用 `endpoint/bucket/object` 格式） |

### 4. 测试连接

配置完成后，系统会自动验证连接。你可以尝试上传一个聊天附件来验证配置是否正确。

## 必选：CORS 跨域配置

由于桌面端使用 WebView 环境，必须配置 OSS 的 CORS 规则才能正常上传。

### Cloudflare R2 CORS 配置

进入存储桶设置 → CORS 策略，添加以下规则：

```json
{
  "cors_rules": [
    {
      "allowed_origins": ["tauri://localhost", "http://localhost:3000"],
      "allowed_methods": ["PUT", "GET", "DELETE"],
      "allowed_headers": ["*"],
      "max_age_seconds": 300
    }
  ]
}
```

### 阿里云 OSS CORS 配置

进入 Bucket → 权限控制 → 跨域设置，添加规则：

| 配置项 | 值 |
|--------|-----|
| 来源 | `tauri://localhost` |
| 来源 | `http://localhost:3000` |
| 允许 Methods | PUT、GET、DELETE、HEAD |
| 允许 Headers | `*` |
| 暴露 Headers | ETag、x-oss-request-id |
| 缓存时间 | 300 |

> **注意**：`tauri://localhost` 是生产环境的 Origin，`http://localhost:3000` 是开发环境的 Origin，两者都需要配置。

## Bucket 权限设置

### 推荐：私有 Bucket

- **读取权限**：私有（通过预签名 URL 临时授权访问）
- **写入权限**：需要 AccessKey 授权

这是最安全的方式，所有访问都通过带签名的临时 URL 进行。

### 可选：公开读 Bucket

如果配置了 `Public Base URL` 指向 CDN，并且希望简化访问流程，可以将 Bucket 设为公开读。但建议至少保持写入权限私有。

## 关于防盗链

**不需要额外配置防盗链。**

桌面端 OSS 使用**预签名 URL（Presigned URL）**机制：

1. **临时有效**：URL 有过期时间（默认 15 分钟，可配置 1-60 分钟）
2. **签名验证**：URL 包含签名参数，无法伪造
3. **自动刷新**：过期后系统自动生成新的预签名 URL

这种机制本身就具备防盗链能力，无需在 OSS 控制台配置 Referer 防盗链。

## 常见问题

### Q: 上传时报 "CORS error" 或 "blocked by CORS policy"

**原因**：OSS 的 CORS 规则未配置或配置不正确。

**解决**：
1. 检查 OSS CORS 配置是否包含 `tauri://localhost`
2. 确保 Allowed Methods 包含 `PUT`
3. 等待 CORS 配置生效（通常几秒到几分钟）

### Q: 提示 "InvalidAccessKeyId" 或签名错误

**原因**：AccessKey 配置错误或权限不足。

**解决**：
1. 检查 Access Key ID 和 Secret Access Key 是否复制正确
2. 确保密钥具有对应 Bucket 的读写权限
3. 对于阿里云，检查是否开启 OSS 服务

### Q: 上传成功但无法访问文件

**原因**：Public Base URL 配置错误或 Bucket 为私有但未正确配置读取权限。

**解决**：
1. 检查 Public Base URL 是否可访问
2. 如果使用自定义 CDN 域名，确保 CDN 已正确回源到 OSS
3. 验证 Public Base URL 拼接后的完整 URL 是否可访问

### Q: Path Style 选项如何设置？

| 提供商 | 推荐设置 | 说明 |
|--------|----------|------|
| Cloudflare R2 | **关闭** | 使用 `bucket.endpoint` 虚拟主机样式 |
| 阿里云 OSS | **开启** | 使用 `endpoint/bucket/object` 路径样式 |

### Q: 配置后上传仍失败，如何排查？

按顺序检查：

1. 检查桌面端日志（设置 → 日志）
2. 检查 OSS 控制台是否有访问记录
3. 使用浏览器开发者工具 → Network 查看具体错误信息
4. 确认 CORS 配置已保存并生效
5. 尝试重新生成 AccessKey 并更新配置

## 安全建议

1. **密钥管理**：AccessKey 存储在桌面端本地 SQLite 数据库中，使用系统密钥链加密
2. **最小权限**：为 Deeting 单独创建一个子账号/RAM 用户，只授予特定 Bucket 的读写权限
3. **定期轮换**：建议每 3-6 个月轮换一次 AccessKey
4. **监控用量**：定期查看 OSS 控制台的使用量和费用
