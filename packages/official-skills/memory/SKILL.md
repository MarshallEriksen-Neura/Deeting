# Knowledge & Memory

## Overview

Manage long-term memory and knowledge base search.

- Runtime: `cloud`, `local`

## Available Tools

- `add_knowledge_chunk` — Store information in long-term memory for future retrieval. Required: `content`. Optional: `metadata`.
- `search_knowledge` — Search personal and system knowledge base. Required: `query`. Optional: `scope`, `limit`.

## Usage Notes

- Keep requests within the tools listed above.
