# Image Generation

## Overview

Generate images from text descriptions using DALL-E, Midjourney, etc.

- Runtime: `cloud`, `local`
- Permissions: `network.outbound`

## Available Tools

- `generate_image` — Generate an image based on a text prompt. Required: `prompt`. Optional: `size`.

## Usage Notes

- Keep requests within the tools listed above.
