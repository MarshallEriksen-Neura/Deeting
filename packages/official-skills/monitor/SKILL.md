# Active Monitor

## Overview

Proactive monitoring and alerting system.

- Runtime: `cloud`, `local`

## Available Tools

- `sys_create_monitor` — Create a persistent monitoring task. Required: `title`, `objective`. Optional: `cron_expr`.
- `sys_list_monitors` — List all active monitors.

## Usage Notes

- Keep requests within the tools listed above.
